# E1：锚定-算力解耦（检验 H1）

> 状态：细化完成 ｜ 更新：2026-11-01 ｜ 依据：TTSPM (2505.20522)、FALCA (2610.28361)、ParaThinker (2509.04475)、Snell (2408.03314)

## 1. 假设与可证伪预测

**H1**：test-time scaling 饱和点由早期误差锚定决定，而非由可用算力总量决定。

- P1：存在阈值 T，顺序算力（迭代/深度）N > T 后 pass@k 边际收益显著下降。
- P2：并行路径 P 增加时，在锚定存在场景下收益 > 顺序场景。
- P3：TTSPM saturation point N\* 与早期锚定率相关（正相关或负相关视定义，见 §5 测量）。

| 基准 | 题数 | 类型 | 说明 |
|---|---|---|---|
| AIME 2024 | 30 | 数学（竞赛级） | TTSPM 直接使用 |
| AIME 2025 | 30 | 数学（竞赛级） | TTSPM 直接使用 |

大模型验证关键格：AIME 2024/2025 + BrowseComp-Plus（60 题）。

## 3. 模型与算力

- 小模型（扫曲面）：Qwen3-4B（本机可跑）→ Qwen3-8B。
- 大模型（验证格）：Qwen3-32B（云端：AMD T4 / Kaggle / ModelScope）。
- 对照：DeepSeek-R1-Distill-Qwen-1.5B / 7B（TTSPM 原设置，用于直接对齐其 Table 1 数字）。

**算力预算估算**（单题单次生成）：
- 1.5B/4B/7B/8B：约 1-8K token/题（AIME/MATH-500）；BrowseComp-Plus 更长，约 8-16K token/题。
- 32B：约 2-4 倍 token。
- N 扫描范围：N ∈ {1, 2, 4, 8, 16, 32}（6 档）。
- P 扫描范围：P ∈ {1, 2, 4, 8, 16}（5 档，仅用于并行臂）。
- 总生成次数 ≈ 908 题 × 6 档（顺序）× 平均 3 次采样 + 并行臂 908 × 5 档 × 平均 8 采样。粗估小模型 30-60 万次生成（含并行），云端验证格 60 题 × 关键格。
- 可行性预检：先用 1.5B 在 AIME 2024 跑 N∈{1,4,8,32} × 2 种子，对照 TTSPM Table 1 的 30.0%→53.3%（N=32）与 70.0% Hit@N，确认复现后放大。

## 4. 实验设计（两维扫描 + 子群分析）

```
                    并行路径 P
        P=1    P=2    P=4    P=8    P=16
N=1   [  x     x      x      x      x  ]  ← 纯并行
N=2   [  x     x      x      x      x  ]
N=4   [  x     x      x      x      x  ]
N=8   [  x     x      x      x      x  ]
N=16  [  x     x      x      x      x  ]
N=32  [  x     x      x      x      x  ]  ← 纯顺序
```

- 每格记录：pass@k、早期步锚定率、TTSPM saturation point N\*。
- 子群分析：按锚定率把题目分层（高锚定 vs 低锚定），比较两子群在「增 N」与「增 P」两个维度上的收益差。

## 5. 测量定义

- **早期步锚定率**：采用 FALCA (2610.28361) 的 anchor-on-incorrect-candidate 定义——在搜索轨迹中，若模型在早期（前 20% 步）锚定在一个不正确候选上，且后续轨迹保持在该候选的邻域（不再探索新区域），记一次锚定。锚定率 = 锚定题数 / 总题数。
- **TTSPM saturation point N\***：按 Eq. (14) 计算，`N* = ceil(ln(ε·p_x/F_max) / ln(1-p_x))`，其中 ε 为边际收益阈值，p_x 为单次生成成功率，F_max 为渐近性能。参数从验证集（MATH-500 8:2 划分）估计。
- **pass@k**：k ∈ {1, 4, 8, 16}（与 TTSPM 的 Hit@N 对齐，TTSPM 使用 N=32 达到 70.0% Hit@N on AIME 2024 1.5B）。

## 6. 关键比较与判据

| 比较 | 判据（H1 成立方向） |
|---|---|
| 固定 P，增 N 的边际收益 | 存在阈值 T，N>T 后 Δpass@k 显著下降 |
| 固定 N，增 P 的边际收益 | 在锚定存在场景，增 P 收益 > 增 N 收益 |
| 锚定率高 vs 低子群 | 高锚定子群在增 N 上收益更低，在增 P 上收益更高 |
| 方差解释 | 「锚定率」解释 N\* 方差的占比显著大于「算力总量」 |

## 7. 统计与鲁棒性

- 每格 3 随机种子，报告均值 ± std。
- 边际收益比较用配对 t 检验（同题同种子）。
- 方差分解用 ANCOVA：`N* ~ anchor_rate + compute_budget`，报告 R² 增量与 F 检验。
- 与 TTSPM Table 1 对齐：R1-Distill-1.5B/7B 的 AIME 2024 平行缩放 N=32 达 53.3%/76.7%，顺序缩放 30.0%/73.3%（1.5B 顺序 N=32 仅 30.0%，对比并行 53.3%——这是「锚定 vs 算力」最直接实证）。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 算力成本高（两维扫描） | 先小模型扫曲面；仅关键格上大模型；云端通道 |
| 锚定率测量无标准定义 | 用 FALCA 定义 + 人工抽检 20 题一致性（Cohen's κ > 0.7） |
| TTSPM 参数估计不稳 | 用 MATH-500 8:2 划分；p_x 从 N=32 数据估计 |
| BrowseComp-Plus 长程成本高 | 仅用小模型 + 缩减到 150 题子集（50 题） |
